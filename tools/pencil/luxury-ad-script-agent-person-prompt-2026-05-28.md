# 高定广告片 · 人物提示词与专业剧本 Agent 修正

## 背景

用户反馈第 2 步虽然有“AI 人物设定提示词”和“风格补充提示词”，但没有 AI 代写按钮；人物描述太粗，无法支撑真人三视图；剧本仍像模板字段填空，画面、动作、台词和痛点不专业；选择“单主角”后仍生成双主角人物表。

## UI/UX 调整

- 在人物提示词 textarea 下新增 `AI 写详细人物提示词` 按钮。
- 在风格补充提示词 input 下新增 `AI 写风格提示词` 按钮。
- 按钮生成内容后，已有剧本失效，用户需重新生成剧本，避免旧剧本继续沿用错误人物。

## 交互规则

- 人物提示词必须补齐：姓名、年龄、职业/身份、脸型五官、发型、肤色、身高体态、上装、下装、鞋子、配饰、手持道具、气质、痛点状态、转折后状态和故事功能。
- 选择 `单主角` 时，AI 提示词和剧本都不得新增客户、同事、家人、顾问、配偶或第二讲解者。
- 有人物时，剧本台词采用说话模式：单主角为 `姓名：短句` 的独白/面对镜头口播，多人物才允许对话。

## 后端生成规则

剧本生成由 6 个专业 agent 角色协同提示：

- 痛点策略 agent：把一句话需求转成可视化痛点。
- 故事编剧 agent：确定人物、冲突、转折和情绪线。
- 画面导演 agent：写每镜观众实际看到的画面。
- 动作导演 agent：写人物/主体/手部/UI 的可拍动作。
- 广告台词 agent：写成片可听到/看到的短句。
- AI 视觉提示词 agent：把镜头意图转换为后续图像/视频模型可执行提示词。
