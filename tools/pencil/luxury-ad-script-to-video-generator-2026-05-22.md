# 高定广告片脚本一键生成界面方案

## 设计依据

参考“视频脚本一键生成视频”的竞品方向，高定广告片不应该让用户先填写产品名称、目标用户、使用场景、风格、镜头数量等多个字段。

竞品心智更接近：

> 用户提供一段内容，系统自动反推广告脚本、分镜表、画面提示词、配音、字幕和视频。

因此本轮设计把高定广告片从“产品故事表单”进一步简化成“脚本/内容一键生成广告片”。

## 新定位

高定广告片 = AI 广告生成器。

用户只需要做一件事：

- 粘贴广告脚本、产品介绍、卖点资料，或输入一句广告需求。

系统负责：

- 识别产品/品牌/服务
- 提取卖点
- 反推广告结构
- 拆成分镜表
- 绑定参考素材
- 生成关键帧
- 生成视频片段
- 配音、字幕、转场和合成

## 首屏原则

首屏只保留一个主任务：

> 告诉我你想生成什么广告。

不要默认展示：

- 产品名称字段
- 目标用户字段
- 使用场景字段
- 镜头数量
- 摄影解构
- 供应商队列
- 画面提示词
- Topview / Seedance / 可灵 / 海螺

这些全部由 AI 自动反推，或放到生成后的“分镜表 / 高级编辑 / 技术详情”。

## 首屏布局

### 中心：一句话/脚本输入区

主标题：

- 高定广告片

副标题：

- 粘贴脚本、产品介绍或一句广告需求，AI 自动生成分镜和广告片。

主输入框：

```text
把广告脚本、产品介绍、卖点资料或一句需求粘贴到这里。

例如：
帮我做一条高端艺术墙广告，突出金属肌理、灯光纹理、定制工艺，适合高端会所和设计师客户，最后引导预约咨询。
```

主按钮：

- 一键生成广告片

次按钮：

- 先生成分镜表

辅助按钮：

- AI 帮我整理内容
- 粘贴示例

### 下方：轻量选项条

只保留 3 个轻量控件：

- 广告类型：自动判断 / 产品宣传 / 品牌故事 / 空间展示 / 活动推广
- 画面比例：自动 / 竖屏 / 横屏
- 生成方式：直接成片 / 先看分镜

默认全部为“自动”。

### 右侧：参考素材与输出说明

右侧不再是表单，而是轻量辅助区：

- 上传参考素材
  - 产品图
  - 品牌图
  - 场景图
  - 参考画面
- 生成设置
  - 配音声音：自动匹配 / 温暖女声 / 商务男声 / 不生成配音
  - 画面比例：自动 / 9:16 竖屏 / 16:9 横屏 / 1:1 方屏
  - 生成尺寸：随比例显示，例如 1080 x 1920、1920 x 1080
  - 预计时长：15-30 秒，可由 AI 根据内容调整
  - 字幕：默认生成，可在高级编辑中关闭
- 人物身份参考（可选）
- 输出内容说明
  - AI 会自动生成脚本分镜
  - 自动生成关键帧
  - 自动合成广告片

### 并排关系

首屏采用左右并排：

- 左侧是主工作流：内容输入区 + AI 反推分镜表，上下堆叠，分镜表不要被右侧栏高度顶到页面下方。
- 人物形象移到左侧主工作流中，放在内容输入区和分镜表之间，作为“真人出镜可选条件”，不要挤在右侧配置栏。
- 右侧是辅助配置：参考素材 + 生成设置 + 生成进度。
- 生成设置沿用当前平台广告数字人的效果：配音使用“当前音色卡 + 选择配音”模式；生成时长、画面比例、像素尺寸、字幕使用 `label + select + hint` 的标准表单控件。
- 这样用户在左侧完成主要创作决策，同时能在右侧随时看到声音、比例、尺寸、素材和进度。

## 生成后的界面

用户点击“先生成分镜表”或“一键生成广告片”后，主输入区下方出现“广告分镜表”。

分镜表不是技术参数表，而是用户能读懂的广告表：

| 镜头 | 旁白/字幕 | 画面内容 | 使用素材 | 状态 |
|---|---|---|---|---|
| 01 开场钩子 | 一句话吸引 | 产品第一眼/品牌氛围 | 主参考图 | 待生成 |
| 02 卖点细节 | 讲核心卖点 | 材质/功能/工艺特写 | 产品图 | 待生成 |
| 03 场景使用 | 进入真实场景 | 使用场景/人物互动 | 场景图/人物参考 | 待生成 |
| 04 品牌收束 | 行动引导 | 品牌记忆点/咨询提示 | 品牌图 | 待生成 |

每行操作：

- 重写这一镜
- 生成这一镜预览
- 锁定这一镜

分镜表必须包含图片：

- 每个镜头至少显示一张“画面预览 / 关键帧缩略图”。
- 未生成前显示 AI 预估的占位画面或绑定的参考素材缩略图。
- 生成关键帧后替换为真实关键帧，用户能直接判断镜头是否符合广告质感。
- 缩略图旁保留“可替换/重生”操作，便于单镜头修改。

底部按钮：

- 确认分镜并生成广告片
- 直接生成广告片

## 状态流

用户不需要知道模型，只看到自然语言进度：

1. 正在理解广告内容
2. 正在生成分镜表
3. 正在生成关键帧
4. 正在生成视频镜头
5. 正在合成广告片
6. 已完成，去任务中心查看

## 与旧方案差异

旧方案：

- 用户先填多个字段。
- 用户需要理解产品、受众、场景、风格、分镜、关键帧。
- 更像后台制作表单。

新方案：

- 用户只填一个内容框。
- AI 自动整理和反推。
- 分镜表是结果，不是前置负担。
- 更接近竞品的“给内容就生成广告”。

## 高级编辑

高级编辑默认隐藏，只在用户点开后显示：

- 镜头数量
- 风格
- 配音
- 字幕
- 像素
- 技术模型
- 画面提示词
- 供应商详情

## 验收标准

- 首屏只有一个明显主输入框。
- 用户不上传素材、不选人物，也能先生成广告分镜表。
- 用户上传多张素材后，分镜表能标记每一镜使用的素材。
- 用户点击“一键生成广告片”后，不需要再理解关键帧/供应商概念。
- 普通广告数字人入口不受影响。
- 商品数字人入口不受影响。
- 任务中心能显示“高定广告片”任务，并保留技术详情用于排障。
