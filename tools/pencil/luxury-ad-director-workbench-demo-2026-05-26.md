# 高定广告片导演工作台 Demo 原型说明 - 2026-05-26

> 范围：仅用于本地 Demo 与产品评审，不接入真实生成链路，不修改现有高定广告片、普通广告数字人、商品数字人和任务中心逻辑。

## 设计目标

- 将高定广告片从“生成步骤表单”临时演示为“广告制作单”：创意 Brief、剧本、分镜/拍摄指南、成片预览。
- 补齐竞品截图中清晰可见的剧本字段：画面、动作、台词、情绪。
- 补齐分镜/拍摄指南字段：时间段、Camera、Action、SFX、素材绑定、预览状态。
- 用对象级状态表达每个剧本段和每个镜头的进度，不改变现有 `luxury_ad` 任务提交逻辑。

## 页面结构

### 顶部项目条

- 项目标题
- 状态：剧本锁定 / 分镜审核 / 成片待合成
- Brief 摘要：产品、市场、规格、风格、CTA

### 左栏：项目与剧本导航

- 当前项目卡片
- 内部阶段：创意、剧本、分镜、成片
- 剧本段列表：
  - `problem`
  - `context`
  - `product_reveal`
  - `feature_1`
  - `feature_2`
  - `demo`
  - `proof`
  - `comparison`
  - `offer`
  - `cta`

### 中栏：剧本详情与分镜拍摄指南

- 创意 Brief 摘要卡
- 当前选中剧本详情：
  - 画面
  - 动作
  - 台词
  - 情绪
- 分镜拍摄表：
  - 时间
  - Camera
  - Action
  - SFX
  - 绑定画面

### 右栏：结果预览

- 当前镜头预览
- 成片预览状态
- 镜头总时长与输出比例
- 参考截图缩略图，仅用于本地 Demo 评审

## 交互约束

- 点击剧本段只切换本地 Demo 状态，不调用后端接口。
- 点击“查看剧本详情”打开弹窗，展示画面、动作、台词、情绪。
- 点击阶段按钮只切换本地视图，不创建任务。
- Demo 页面不进入现有导航，不影响任何生产生成逻辑。

## 后续正式实现边界

- 正式实现时新增 `state.luxuryAd.scriptBlocks` 和 `state.luxuryAd.shotGuides`，再通过 adapter 转换为现有 `segments`。
- `/api/dh/luxury-ad/storyboard` 可向后兼容地返回 `script_blocks`、`shot_guides`，但保留现有 `segments` 字段。
- `/api/dh/spaces/generate`、任务中心、普通广告数字人、商品数字人不作为第一阶段改造范围。

## 2026-05-26 追加：纠偏后的竞品学习重点

本 Demo 不应理解为“复刻竞品页面”。正确目标是把竞品做得好的制作能力拆出来，结合到 VIDO 高定广告片：

### 竞品有、VIDO 当前不足的能力

- 全局剧本：先锁定整条广告的故事、角色、情绪曲线、世界设定、声音方向和 CTA。
- 逐镜头导演描述：每个镜头除了台词，还要有画面、人物行为、情绪、氛围、镜头/景别、SFX/Audio、AI 可执行提示词。
- 分镜交付件：生成出的故事板不是单纯图片，而是带 Time、Camera / Lens、Action / Visual、SFX / Audio 的导演审核稿。
- 清晰界面：主工作区始终围绕当前阶段的一个主任务，不把任务列表、生成状态和核心内容混在一起。

### VIDO 结合方式

- 保留现有高定广告片生成链路和任务中心，不直接改 `/spaces/generate`。
- 新增 `directorPlan.globalScript`：用于全局剧本与情绪曲线。
- 新增 `directorPlan.shotBible[]`：每镜头保存画面、动作、氛围、镜头、SFX、字幕和模型提示词。
- 故事板审核通过后，通过 adapter 把 `shotBible[]` 转成现有 `segments`，继续使用当前片段生成与合成逻辑。
- UI 上不照搬竞品：采用 VIDO 现有左侧项目 + 主工作区结构，但把全局剧本、镜头导演表、故事板审核三层分清楚。

## 2026-05-26 追加：按真实竞品链路重排为 7 阶段
