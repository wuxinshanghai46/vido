# Codex Pencil Integration

Pencil Project is the required UI/UE entry point for VIDO frontend work.

## Required Workflow

1. Check this directory before changing UI, UE, frontend layout, modals, workflows, navigation, or interaction states.
2. Use Pencil Project assets or notes as the source of truth for layout density, hierarchy, states, and flow.
3. If no Pencil file exists and the task is a small corrective UI fix, document the assumption in the session and keep the change narrow.
4. For new screens or larger redesigns, create or update a Pencil prototype artifact before implementation.
5. Keep Pencil source files, exported previews, and review notes in `tools/pencil/`.

## Current Local Asset

## Codex Note

There is no installable Pencil connector in the current Codex plugin list. Until one exists, this directory acts as the project-level Pencil integration contract for Codex.
