# 高定广告片顺序分镜定义

> 2026-05-24 · 产品/UE 定义 · 只约束“高定广告片”模块

## 结论

高定广告片不是“上传几张参考图 + 一段需求 + 自动生成视频”。

它应当是“商品宣传故事片生成器”：用户先提供主商品和参考画面，AI 先生成一张可审核、可编辑、按顺序执行的分镜表，再逐镜头生成关键帧和视频，最后按镜号合成成片。

如果没有清晰顺序，模型会自由发挥，把参考图当素材池乱用，导致商品跑偏、镜头重复、广告词和画面不对应，并持续浪费模型积分。

## 参考结构

参考视频中的核心不是某个模型，而是“顺序分镜表”：

| 字段 | 作用 |
|---|---|
| 镜号 | 决定成片顺序，不能自动乱序 |
| 画面 | 对应这一镜头使用的参考图或预览图 |
| 景别/镜头 | 微观全景、中远景、极近景、特效环绕、跟随拍摄等 |
| 时长 | 每个镜头占几秒，合计等于成片时长 |
| 内容 | 这一镜头画面发生什么 |
| 其他 | 旁白/字幕、风格、光线、镜头运动、情绪 |

## 模块定位

高定广告片应定位为：

“围绕一个主商品/品牌，用多个按顺序排列的镜头讲清楚一个宣传故事。”

不等于：

- 普通数字人口播
- 一键文生视频
- 多张背景随机混合
- 主商品 + 多张参考图自由生图
- 只有首帧预览，没有分镜顺序

## 用户输入

### 必填

1. 主商品
   - 商品主图或产品图。
   - 所有镜头都围绕它展开。
   - 不能被参考图覆盖。

2. 广告需求
   - 产品是什么。
   - 核心卖点是什么。
   - 给谁看。
   - 想要的风格。
   - 最后希望用户做什么。

### 推荐

3. 镜头参考图
   - 不是“背景池”。
   - 是镜头顺序参考：开场参考、材质参考、场景参考、品牌收尾参考等。
   - 上传后应该允许用户指定或自动建议每张图对应哪个镜头。

### 可选

4. 人物参考
   - 只在需要人物出现时使用。
   - 人物不是默认站桩数字人。
   - 人物用于身份一致性，不应挤占商品故事主线。

5. 配音、字幕、背景音乐
   - 属于成片后期。
   - 不应该影响分镜生成。
   - 配音/字幕来自每个镜头的广告词字段。

## 标准生成流程

1. 上传主商品
2. 写广告需求
3. 上传/整理镜头参考
4. 生成顺序分镜表
5. 用户审核并修改每个镜头
6. 逐镜头生成关键帧
7. 逐镜头图生视频
8. 按镜号合成成片
9. 后期加字幕、配音、背景音乐

## 分镜表字段

每个镜头必须有以下字段：

| 字段 | 说明 |
|---|---|
| 镜号 | 01、02、03，决定顺序 |
| 故事阶段 | 开场、产品亮相、材质细节、场景价值、卖点强化、行动引导 |
| 画面参考 | @主商品、@参考1、@参考2，或已生成关键帧 |
| 景别/镜头 | 微观全景、中远景、极近景、特效环绕、跟随拍摄、固定镜头等 |
| 时长 | 秒数 |
| 画面内容 | 这一镜头看到什么、如何运动 |
| 屏幕广告词/字幕 | 成片里真正出现的短广告词 |
| 风格/旁白提示 | 光线、情绪、质感、语气 |
| Topview 式提示词 | 给图生视频模型的可执行提示词 |
| 状态 | 待确认、待生成关键帧、已锁定参考、已生成视频 |

## 广告词规则

广告词必须是成片可用文案，不是用户需求复述。

错误示例：

- “帮我做一条高端广告片”
- “突出金属肌理、灯光纹理”
- “适合高端会所和设计师客户”

正确示例：

- “一眼看见材质的高级感”
- “让空间拥有更安静的锋芒”
- “每一道纹理，都经得起近看”
- “为高端空间，留下记忆点”

## 画面内容规则

画面内容只描述视觉，不写广告词，不写用户需求。

示例：

- “纯色背景中，主商品以慢速推近方式出现，金属纹理被侧光勾出。”
- “镜头贴近材质表面，沿纹理横向平移，强调细节与反光层次。”
- “切到真实空间应用，商品/材质作为视觉中心与环境融合。”

## 顺序模板

默认 6 镜头：

| 镜号 | 故事阶段 | 景别/镜头 | 默认时长 | 目标 |
|---|---|---|---:|---|
| 01 | 开场钩子 | 微观全景 / 固定或慢推 | 2-3s | 建立第一眼吸引 |
| 02 | 产品亮相 | 中远景 / 缓慢前进 | 3-4s | 让主商品成为中心 |
| 03 | 材质细节 | 极近景 / 微距平移 | 2-3s | 展示纹理、工艺、质感 |
| 04 | 场景价值 | 中景 / 平移或切换 | 3-4s | 说明适合什么场景 |
| 05 | 卖点强化 | 特写或环绕 | 2-3s | 强化核心卖点 |
| 06 | 行动引导 | 品牌收尾 / 固定镜头 | 2-3s | 收束记忆点与转化 |

## 界面原则

1. 分镜表必须是主工作区核心。
2. 每行要能直接编辑广告词、画面内容、景别、时长、绑定参考图。
3. 用户应该能看出“开场是什么、之后是什么、最后是什么”。
4. 参考图要按镜头绑定，不应只放在右侧素材池。
5. 生成按钮必须遵守顺序：没有确认分镜表，不能生成关键帧；没有关键帧，不能合成视频。
6. 任何重新生成都要说明会影响哪些镜头，避免用户误以为改了但实际没变。

## 开发验收标准

- 生成故事板后，页面显示顺序分镜表，而不是普通卡片堆叠。
- 每个镜头都有独立广告词，且不是用户 brief 原文。
- 每个镜头都有景别/镜头类型和时长。
- 每个镜头都显示绑定的参考图或主商品。
- 用户可以逐行修改。
- 逐镜头生成必须按镜号顺序执行。
- 合成视频必须按镜号顺序拼接。
- 只影响高定广告片模块，不影响广告数字人、商品数字人、形象生成和任务中心其他分类。
