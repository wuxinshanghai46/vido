# 高定广告片 · 分镜生产台优化说明 - 2026-05-23

## 目标

把高定广告片从“脚本生成器 / 一键成片”表达，调整为“主商品驱动的广告分镜生产台”。

用户应理解为：

1. 先锁定一个主商品。
2. 写广告 brief。
3. AI 生成广告分镜脚本。
4. 每个分镜先生成画面预览。
5. 每个预览再图生视频，最后剪辑合成并进入后期配乐。

## 设计原则

- 主商品是必填资产，参考素材不能覆盖主商品。
- 分镜脚本是核心产物，不是直接生成视频。
- 每个镜头必须显示镜头任务、时长、旁白/字幕、画面内容、镜头运动、使用素材和状态。
- 人物是可选参考，不是默认数字人口播。
- 背景音乐属于成片后期，必须单独配置，合成后再叠加。

## 本轮界面优化范围

- 只调整高定广告片页面文案、信息层级、分镜表字段和后期配乐位置。
- 不改普通广告数字人、商品数字人、生成形象、作品库等模块。
- 不改供应商链路，只让页面和现有逻辑更一致。

## 验收点

- 页面标题说明明确“一个商品 + 多个分镜 + 合成广告片”。
- 步骤条明确为：主商品、广告 brief、广告分镜、镜头预览、成片后期。
- 分镜表不再像普通文本表，而是能看出每个镜头要拍什么、说什么、怎么动。
- 背景音乐不在普通生成设置里，独立显示为成片后期。
