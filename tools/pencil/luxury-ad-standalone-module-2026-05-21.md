# 高定广告片独立模块说明

## 背景

用户反馈高定广告片不应继续挤在“广告数字人”的普通单镜头导览界面里。普通广告数字人的“背景/展示画面”是展墙讲解必填素材；高定广告片更像独立广告项目，素材语义应是“参考画面 / 产品物料”，用于多镜头分镜和 Topview Image2Video 参考流。

## 本次 UI/UE 调整

- 左侧“广告带货”新增独立入口：`高定广告片`。
- `广告数字人`入口默认只进入普通单镜头导览流程。
- `高定广告片`入口默认进入高定多镜头流程，不再要求用户先从普通广告数字人里切换。
- 复用同一个工作台 DOM 与后端接口，但通过前端路由 tab 隔离：
  - `space-guide` -> `adMode=standard`
  - `luxury-ad` -> `adMode=luxury`
- 普通/高定切换按钮从工作台内隐藏，避免用户感知两个模块挤在同一个页面。

## 文案语义

普通广告数字人：
- 标题：广告数字人
- 素材：广告背景 / 展示画面
- 目标：单镜头展墙导览、带人物首帧质检、稳定讲解视频

高定广告片：
- 标题：高定广告片
- 素材：参考画面 / 产品物料
- 目标：4-8 个广告镜头、Topview/Image2 风格关键帧、Topview Image2Video 逐镜头成片

## 隔离原则

本次只调整前端入口、页面文案和 tab 与 `adMode` 的绑定；后端仍使用已部署的 `luxury_storyboard` / `topview_i2v` 链路。普通广告数字人、商品数字人、形象生成、声音克隆和作品库不读取高定模块状态。

## 2026-05-22 补充：人物一致性

- 高定广告片的人物为可选“身份参考”，不是普通广告数字人的固定导览员。
- 不选择人物时，界面应表达为产品/场景/品牌广告片。
- 选择人物时，界面应明确说明会锁定同一人物身份：脸型、发型、年龄感、体型和服装风格保持一致；姿态、表情、镜头角度和场景光线可随分镜变化。
- 该一致性提示仅出现在高定广告片入口，不影响普通广告数字人的单镜头导览链路。
