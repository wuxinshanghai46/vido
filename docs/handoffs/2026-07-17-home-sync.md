### 3.1 `e647aac`：降低失败视频生成的无效消耗

核心变化：

- 明确区分“提交模型前失败”和“已经提交模型后失败”。
- 提交前的预检失败按 0 成本处理；一旦拿到供应商任务 ID，后续失败不再错误标记为 0 成本，而是进入“计费状态未知/待核对”。
- 保存供应商任务 ID、提交时长和估算成本，方便追踪漫路等平台的实际账单。
- 自动修片默认次数由 2 次降为 1 次，减少失败任务的连锁重试。
- 人数不匹配、合规、计费、供应商明确拒绝等确定性错误不再进入自动修片。
- 对安全拆分出来的单镜头结果按来源和拓扑复用，避免同一镜头重复付费生成。

这部分解决的是“失败仍不断重试、账单看不清、已有成果无法复用”的结构性问题。真实供应商调用仍必须在额度确认、成本上限和人工确认之后进行。

## 5. 明天建议的优化顺序

### P0：先做画布真实使用验收

1. 创建电商广告模板和故事剧情模板各一个项目。
2. 验证新增节点、移动、连线、替换单输入、保存、刷新恢复。
3. 验证未连完的草稿可以保存，但运行预检必须阻止不完整流程。
4. 验证任务页、运行详情和成本台账能对应到同一个项目/版本/运行。
5. 只执行不产生费用的计划预览和模拟任务，不直接做真实供应商生成。

### P1：补齐专业画布编辑体验

1. 增加边的选中、删除和重连能力。
2. 增加撤销/重做、快捷键和误操作恢复。
3. 增加大画布平移、小地图、框选和自动布局。
4. 优化多节点下的自动保存合并、冲突提示和性能。
5. 节点内或运行详情中增加每一步产物预览，尤其是单镜头图片、视频、音频和合成结果。

### P1：继续收紧真实生成成本

1. 真实调用前展示模型、单价、预计次数、预计金额和最大预算。
2. 未配置成本上限或没有人工确认时，不允许提交付费任务。
3. 供应商返回任务 ID 后禁止盲目自动重试，先轮询或人工核对原任务。
4. 对“计费未知”任务单独告警，避免用户误以为失败就是零成本。
5. 先用最便宜的预检/低清样片验证提示词、素材和镜头结构，再允许高清生成。
6. 真实验收只选 1 个镜头、1 次调用，确认成功率和账单后再扩大范围。

### P2：模块治理

1. 持续检查单文件体积，页面、节点定义、图编辑、任务、存储、供应商适配、产物和成本必须分层。
2. 新增节点使用注册表/插件式扩展，不在一个 JS 内持续堆分支。
3. 公共能力只能下沉到无业务语义的基础层，防止视频画布再次演变成旧剧情广告式耦合模块。
4. 为迁移、任务恢复、取消、重试、幂等和成本状态增加更完整的回归测试。
