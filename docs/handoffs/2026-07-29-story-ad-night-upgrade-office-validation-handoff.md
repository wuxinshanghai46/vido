## 三、今晚处理的真实用户问题

### 3.1 新任务仍读取旧任务、任务编号或内容混用

修复后的权威链路：

```text
显式新建任务
→ 创建新的 task_id 与会话代次
→ 所有恢复、轮询、自动保存和生成响应校验 task_id
→ 旧会话或旧任务迟到响应被丢弃
→ 新任务只读取自己的上下文、输出和进度
```

已覆盖：

- 不同任务 ID 隔离；
- 不同行业输入隔离；
- 任务切换后的旧响应隔离；
- 旧轮询和自动保存不得写回新任务；
- 新建任务不再自动恢复上一个任务。

### 3.2 生成时没有耗时和比例

人物、场景、剧本、分镜、关键帧、视频和合成共用统一进度状态：

- 开始提交时立即显示“准备中 / 0%”；
- 服务器返回新 `generation_id` 后接管真实进度；
- 显示当前阶段、已耗时、完成比例和当前镜头；
- 关键帧显示真实活动镜头与并发数量；
- 旧 generation 的终态进度不能覆盖新一轮生成；
- 失败后保留失败卡片，不再瞬间恢复成 0/9。

### 3.3 人物年龄修改后仍使用旧年龄

人物年龄、外貌、服装、发型和避坑项现在以当前编辑值为唯一权威：

```text
当前 DOM / 结构化人物设定
→ 标记人物资产过期
→ 自动保存最新修订
→ 生成请求绑定最新内容版本和快照
→ 旧人物资产或迟到响应不得覆盖
```

单人模式会同步当前人物年龄；多人模式按各自人物档案独立保存，不会把一个人的年龄错误覆盖到其他人物。

### 3.4 场景描述修改后，AI 空间设定仍使用旧内容

场景 AI 辅写改为“只补齐当前空字段，保留用户已修改字段”：

- 当前 `layoutText`、`materialLightText`、`interactionText`、`negativeText` 为权威；
- 请求直接携带当前场景设定和当前场景规划；
- 不再回退到旧 `space_description`；
- AI 返回后再次校验任务、会话和编辑序号；
- 用户在生成过程中继续编辑时，迟到结果直接丢弃并提示按最新内容重试。

### 3.5 关键帧部分失败与错误恢复

关键帧通用恢复规则：

- 保留已成功镜头；
- 只补齐未生成或未通过的镜头；
- 供应商 5xx、审核失败或计费不确定时打开批次熔断；
- 熔断后停止尚未提交的镜头，避免继续付费；
- 错误提示列出直接失败镜头和依赖阻断镜头；
- 不再用单任务关键词补丁或自动盲目重试。

### 3.6 旧剧情广告入口

旧入口已经从以下位置彻底移除：

- 左侧导航；
- 任务中心筛选；
- 数字人形象用途入口；
- 旧项目状态恢复路径。

旧深链统一重定向到当前剧情广告；旧 API 保持 `410 Gone`。本地真实页面检查结果为：旧入口 0 个，当前“剧情广告”入口 1 个。

### 3.7 所有阶段新增“停止生成”

现在以下阶段均纳入统一取消契约：

- 广告需求 AI 辅写；
- 剧情与表演 AI 辅写；
- 人物设定 AI 辅写；
- 场景设定 AI 辅写；
- 人物 / 宠物资产；
- 场景参考图；
- 场景配置；
- 剧本与脚本包；
- 分镜表；
- 关键帧；
- 配音；
- 镜头视频；
- 最终合成。

停止生成的数据流：

```text
点击“停止生成”
→ 前端标记 cancelRequested
→ 按 generation_id 或 task_id 调用服务器取消接口
→ AbortController 中断浏览器等待
→ 服务器取消上下文中断模型 / 媒体 / TTS 请求
→ 输出、阶段和任务元数据写入统一检查取消状态
→ 迟到结果被拒绝，不能覆盖当前任务
```

即使供应商 SDK 忽略中断信号，当前请求也会立即进入已取消终态，后续迟到写入会被服务端存储门禁拒绝。

### 3.8 错误提示精确到具体位置和处理方法

错误提示现统一包含：

- 失败阶段；
- 人物、场景名称或字段；
- 关键帧 / 视频镜头编号；
- 原始失败原因；
- 用户应该修改什么；
- 哪些情况不需要修改创作内容；
- 支持编号；
- 是否允许重试。

示例分类：

- 人物一致性：提示年龄、外貌、服装、发型或四视图问题；
- 场景一致性：提示空间布局、材质 / 色彩 / 光线、互动机位或禁止项；
- 关键帧：列出直接失败镜头，成功镜头保留；
- 模型配置：提示管理员检查模型启用状态和凭证；
- 额度 / 限流：明确暂时不要重复提交付费生成；
- 供应商超时 / 5xx：说明不需要修改内容，从当前步骤稍后重试；
- 用户取消：说明已停止，迟到结果不会覆盖任务。
