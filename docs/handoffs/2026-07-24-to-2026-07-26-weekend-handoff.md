## 五、当前数据流

### 5.1 主体

```text
用户需求/人物与宠物资料
→ 结构化逐主体档案
→ 逐主体四视图
→ 逐主体视觉合同
→ 聚合主体合同
→ 关键帧引用与视频逐帧 QA
```

### 5.2 场景

```text
广告需求
→ scene_plan.spaces[] 独立物理空间
→ 稳定 scene_id
→ V7 2×2 母图
→ 五类派生视图
→ 需求/真实性/跨视图/空间覆盖 QA
→ 独立机位 QA
→ 完整空间锁定
→ 分镜 scene_id 绑定
```

### 5.3 失败恢复

```text
供应商/QA 失败
→ 场景级错误与支持编号
→ 检查点保存已成功视图和候选版本
→ 计费状态判断
→ 指纹精确匹配
→ reverify 或只补缺失视图
→ 不重做已成功图片
```

### 5.4 跨场景

```text
相邻分镜 scene_id
→ 同场景/跨场景分类
→ 转场类型与匹配锚点
→ 声音桥与进入/退出方式
→ 前镜尾帧/后镜首帧验证
→ 跨场景专用 QA
→ 最终合成
```

### P1：真实检查跨场景转场

用一个公园镜头接一个家庭镜头，检查：

- 转场类型是否允许用户修改；
- 转场时长是否合理；
- 动作/视觉匹配锚点是否对应真实画面；
- 声音桥是否真正提前进入或延后退出；
- 前镜尾帧和后镜首帧并排预览是否清晰；
- 跨场景 QA 是否使用跨场景标准，而不是同场景背景连续标准。

### P1：真实新任务验收

代码与回归已经覆盖结构和失败恢复，但真实供应商效果仍需新任务证明：
