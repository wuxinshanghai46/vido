## 3. 最近更新的具体内容

### 3.1 场景一致性知识进入最终生成链路（v65）

- 场景知识升级为多尺度证据：总览轮廓、空间关系、局部互动、材质细节。
- 几何、资产清单、环境状态、灯光和色彩锚点跨视图保持一致。
- 知识不是普通文章检索，而是编译成任务级不可变 `runtime_policy` 快照，并进入场景、关键帧、视频提示、QA、指纹和 trace。
- 旧任务不会因知识更新中途漂移；新任务按版本和冲突域选择生效规则。

### 3.2 多场景资产档案与 PNG 导出（v67）

- 资产中心每个场景独立显示主视、反向、互动、材质细节和俯视布局五类证据。
- 完整场景档案包含结构锚点、路线、道具摆位、材质、灯光、QA 和分镜引用。
- 支持浏览器本地导出 1800×2400 PNG；导出读取现有资产，不调用模型。
- 原有场景世界、3D、360°、机位和路线执行链保持不变。

### 3.3 内容类型与模式化 AI 帮写（v69）

- 内容类型移动到内容目标下方，AI 帮写先读取用户亲自选择的广告或剧情，再打开对应多行弹窗。
- 广告围绕产品/服务、受众、价值、依据和行动补充，禁止编造功效、价格、资质和品牌事实。
- 剧情围绕人物、关系、地点、事件、情绪和主题补充，禁止凭空加入商品、购买和营销转化。
- 取消弹窗在任何模型请求前退出，不产生调用费用。

### 3.4 内容类型下拉与广告主体自动识别（v71）

- 页面现在只有一个原生下拉框：`请选择 / 广告 / 剧情`；可见“产品或主题”字段已移除。
- 修改前数据流：手工 `product_subject` 可覆盖自动推断，泛化目标或受众文本可能进入 context 和下游。
- 修改后数据流：内容类型 + 内容目标/参考分析 → `contextBuilder` → `productAssetResolver` 统一校验具体产品、服务或品牌 → 持久化 → AI 帮写/资产规划/后续生成；剧情强制空主体。
- “广告的核心目标是传达产品”“产品”“面向年轻家庭”“一支”等泛化内容会被拒绝；“为 LibTV 流媒体服务制作一支面向年轻家庭的广告”可识别为 `LibTV 流媒体服务`。
- 广告主体不明确时，AI 帮写和资产规划均在模型调用前阻止并提示补充；不编造、不静默 fallback、不重复付费。
