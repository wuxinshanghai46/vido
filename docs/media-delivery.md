# VIDO 统一媒体交付

平台图片和视频统一遵循以下交付规则，业务模块不应再自行把原始大图直接放入列表或弹窗。

## 图片

- 原图地址保持不变，用于下载、模型引用和 QA。
- 页面预览在原地址后使用 `thumb=<width>&format=webp`。
- 支持宽度范围 120–2560 像素；服务端按源文件大小、修改时间、宽度、质量和格式生成不可变缓存键。
- 公开媒体返回 `public` 长缓存；需要登录或归属校验的媒体返回 `private` 长缓存并区分授权信息。
- 同一变体的并发首次请求会合并，避免重复压缩。
- 可显式请求 `format=avif`；默认使用编码更快、兼容性更高的 WebP。

## 视频

- 视频端点应使用 `mediaDeliveryService.streamVideo` 或等效的标准 Range 响应。
- 列表视频默认 `preload=none`，接近视口后切换为 `metadata`；自动播放视频不受影响。
- 下载地址和播放地址分离，页面卡片优先显示已有封面图。

## 前端

所有平台 HTML 页面都加载 `/js/media-delivery.js`。该脚本负责：

- 识别平台生成图片并选择 320/640/960/1280 等响应式变体；
- 懒加载非首屏图片；
- 鼠标接近预览入口时预取高清预览；
- 清理公开媒体 URL 中无必要的登录 Token，提升浏览器和后续 CDN 的缓存命中率；
- 动态加入页面的图片和视频同样自动接入。

## 基础设施

应用层已输出稳定 URL、不可变缓存头和小体积变体。接入对象存储或 CDN 时，应按完整查询参数缓存图片变体，并忽略公开媒体 URL 中已被前端移除的鉴权参数。原图和私有媒体不能配置为匿名公共缓存。
