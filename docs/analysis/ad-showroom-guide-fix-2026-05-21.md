# 广告数字人展厅导览问题修复记录 2026-05-21

## 团队结论

广告数字人导览不是普通口型数字人任务。竞品效果的关键是先生成自然融合的首帧，再用全场景 I2V/营销视频模型生成连续镜头，最后才考虑配音、字幕、压缩。不能把口型同步模型当作主视频生成模型。

## 根因

1. 严格预览曾允许模板贴片兜底，失败后会出现 `KEYFRAME_TEMPLATE_COMPOSITE_REJECTED`，用户看到的是“生成不出图”。
2. 预览确认后的强制成片仍走 `ad_avatar.lip_sync`，这种链路更擅长嘴型和轻微头部动作，不擅长人物走动、手部讲解、空间延展。
3. 视频阶段的动作提示虽然写了“走动、指向、延展”，但没有进入真正的全场景视频模型时，最终只会退化成裁剪、缩放和轻微镜头。

## 已执行改造

1. 严格预览不再接受模板贴片兜底。首帧必须是自然融合的 AI 导览员画面，否则直接返回可诊断错误。
2. 广告导览成片改为优先走 `ad_avatar.marketing_video`，优先 Topview，失败后再走 Seedance I2V，不再先走口型同步。
3. 预览确认后的强制链路改为“已确认首帧 -> 完整场景视频生成”，口型同步只保留为普通广告备用路线。
4. 动作提示拆到视频层，明确要求小步走位、手部抬起、开放掌指向/扫过材质、眼神从展示区回到镜头、慢速 dolly/truck/parallax，而不是静态缩放。
5. 人物动作轨去掉 `tiny push-in` 这类保守约束，改为真实导览动作与空间运动约束。

## 验证点

1. 生成展墙讲解预览时，失败应显示具体首帧生成/质量检查原因，不应再出现模板贴片合成结果。
2. 确认预览并合成视频时，任务阶段应进入 `full_scene_video` / `topview_m2v` / `video`，不应直接进入 `lipsync_running`。
3. 成片应比旧版更接近连续导览镜头：人物有走位或身体重心变化，手部有清楚介绍动作，背景有空间延展和视差，不只是缩放。
