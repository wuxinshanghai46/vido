## 验收原则

1. 所有核心步骤必须在生产页面通过浏览器真实点击完成；接口、数据库和日志只能作为辅助证据。
2. 广告与剧情使用两个全新且相互隔离的验收任务，不复用用户已有任务或旧生成结果。
3. 每一步记录页面入口、用户操作、可见结果、任务状态、模型调用、失败与恢复过程。
4. 逐页检查中文显示，不允许乱码、内部错误码、供应商原始错误或含义不清的操作提示。
5. 任何付费操作均记录确认页面、目标单元和调用结果；失败后不盲目重复提交。
6. 未实际走过的功能不得写为通过；无法到达最终成片则整条流程保持失败或阻塞。

## 问题记录强制模板

后续每个问题必须包含以下字段，缺少生产界面复测时不得标记为“已解决”：

- **问题现象**：用户实际看到什么。
- **复现步骤**：从哪个页面开始，依次点击什么。
- **已确认事实**：页面、接口、服务、文件、数据库或模型调用中已经取得的证据。
- **代码根因**：最早产生错误状态的位置；不能只描述末端报错。
- **外部系统推断**：无法由本系统直接证明的供应商或网络推断，必须与事实分开。
- **解决方案**：修改了什么，以及修改前后的界面或数据流。
- **影响范围**：涉及页面、任务阶段、已有数据、并发、缓存、计费和后续产物。
- **定向复测**：原问题是否能够稳定复现并在修改后通过。
- **相邻复测**：相关选择、保存、刷新、重进页面和下一步是否正常。
- **生产界面复测**：在生产浏览器真实操作的可见结果和截图。
- **完整流程复测**：广告、剧情哪条完整流程覆盖了该问题。
- **最终状态**：未修复 / 本地已修复待生产 / 生产已修复待完整流程 / 已关闭。

## 界面缺陷记录

### UI-001：选择“不使用参考材料”后上传入口仍显示

- **问题现象**：下拉框已经显示“否，暂不使用”，参考视频和商品 / 服务主体入口仍然显示。
- **复现步骤**：新建项目 → 高级配置 → 是否使用参考材料 → 选择“否，暂不使用”。
- **已确认事实**：DOM 元素存在 `hidden` 属性，但浏览器计算样式仍为 `display:grid`，元素实际可见。
- **代码根因**：`workspace.css` 的 `.material-list { display:grid; }` 作者样式覆盖了浏览器对 `[hidden]` 的默认隐藏规则；最早错误发生在样式层，不是选择事件或数据保存层。
- **外部系统推断**：无。
- **解决方案**：增加 `.material-list[hidden] { display:none; }`；选择事件继续只切换 `hidden`。修改前为“属性隐藏但 CSS 强制显示”，修改后为“属性与计算样式共同隐藏”。
- **影响范围**：新建及编辑项目的高级配置显示逻辑；不修改任务数据、不删除已有参考材料、不触发模型或费用。
- **定向复测**：本地浏览器选择“否”后 `visible=false`、`display=none`；选择“是”后 `visible=true`、`display=grid`，通过。
- **相邻复测**：v235 UI、工作区、参考视频、计费恢复、发布完整性通过；生产“否→是”往返选择通过。
- **生产界面复测**：生产 v235 页面选择“否”后可见“粘贴链接”按钮 0、商品“添加”按钮 0；切回“是”后分别恢复为 1。剧情新建任务选择“否”后两类入口均为 0。
- **完整流程复测**：广告任务使用“是”，剧情任务使用“否”，已覆盖互斥分支；后续完整成片仍未完成。
- **最终状态**：生产显隐已修复，待两条最终成片流程完成后关闭。

### AI-001：参考视频语义总编首个模型超时后未切换候选

- **问题现象**：广告任务参考视频镜头证据显示 `1/1` 完整保留，但分析在 82% 失败；页面显示“实际尝试 1/3 个本阶段候选（全部可用候选 5 个）”。
- **复现步骤**：广告任务选择使用参考材料 → 粘贴公开视频链接 → 授权并开始读取 → 等待参考分析。
- **已确认事实**：视觉镜头证据 1/1 已保存；失败阶段为 `new_story_ad.reference_video_synthesis`；首个 `apismile/gpt-5.5` 返回 `TIMEOUT_OR_NETWORK`；没有读取第二候选。
- **代码根因**：语义总编单候选超时为 120 秒，而阶段总预算默认也为 120 秒。首个调用耗尽总预算后，候选循环在第二次迭代前退出。
- **外部系统推断**：首个供应商为何超时属于外部网络或供应商行为，当前不能证明；“没有切备用模型”属于已确认的本系统缺陷。
- **解决方案**：参考语义阶段显式配置 `maxCandidates: 3`、`stageBudgetMs: 300000`，允许首个 120 秒超时后继续候选；仍复用已完成镜头证据。
- **影响范围**：仅参考视频语义总编文本阶段；不重读镜头、不覆盖已保存视觉证据；可能增加备用文本模型调用，但避免整条分析无故停止。
- **定向复测**：新增时钟回归，模拟首个候选耗尽 120 秒，确认进入后续候选；参考视频模块 199 项断言通过。
- **相邻复测**：UI、视觉资产失败恢复、未知计费保护和不可变发布门禁通过。
- **生产界面复测**：v237 上线后原任务点击“仅补齐缺失语义”，确认没有重读镜头；随后暴露 AI-002，故本项预算根因已修复但完整阶段仍未通过。
- **完整流程复测**：广告流程覆盖；剧情无参考材料，不经过此阶段。
- **最终状态**：预算根因已修复；完整参考分析仍受 AI-002 阻塞。

### AI-002：参考视频语义结构无效时未切换候选

- **问题现象**：v237 生产复测时首个模型不再超时，而是返回结构校验无效；页面仍显示仅尝试 `1/3`，参考分析再次失败。
- **复现步骤**：在广告任务已保留 1/1 镜头证据的状态下，点击“仅补齐缺失语义（不重读镜头）”并确认。
- **已确认事实**：失败代码为 `PROVIDER_RESPONSE_INVALID`；网关只对登记在 `MANAGED_RECOVERY_FALLBACK_STAGES` 的阶段在结构无效后继续候选；参考语义阶段未登记。
- **代码根因**：`new_story_ad.reference_video_synthesis` 缺少受管恢复阶段登记，因此结构不合格被网关当作定向修复终止条件，未切备用模型。
- **外部系统推断**：模型为何返回不合格结构属于外部输出质量；本系统应按已有三个候选策略继续切换，这是代码责任。
- **解决方案**：将参考语义阶段加入受管恢复候选集合；回归连续模拟“首个超时、第二个结构无效、第三个成功”。
- **影响范围**：参考语义文本阶段候选切换；不影响内容安全、隐私和不可重试错误的立即停止规则。
- **定向复测**：连续三候选回归通过；参考视频分析 199 项、v238 定向套件、16 项发布传输门禁、11 项制品完整性检查通过。
- **相邻复测**：v238 生产部署 667 文件哈希通过，内外网健康与 SQLite 均为 `ok`，活动未知计费任务 0。
- **生产界面复测**：v238 已上线；广告原任务已再次提交“仅补齐缺失语义”，当前等待生产结果。
- **完整流程复测**：广告流程正在覆盖。
- **最终状态**：生产复测中，尚不能标记已解决。
